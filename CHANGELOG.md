# Changelog

## 1.2.0
- Optional character portraits per track, laid under the notes at a chosen opacity
- Lyric box with karaoke highlight, fed by the notes, typed text or an .lrc file
- Background image or video with dim and blur
- Export range, plus 16:9, 9:16 and 1:1 shapes
- Save and load looks as a file
- Keyboard shortcuts and a help list
- Light / dark / auto theme button
- Version label in the header
